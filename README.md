# BookShelf

**BookShelf** — простий локальний вебзастосунок для ведення особистої бібліотеки. Проєкт розробляється в межах практичних робіт із застосуванням AI-агента та інфраструктури **Agent Harness**.

## Призначення та користувачі

Застосунок призначений для користувачів, які хочуть зберігати перелік власних книг, знаходити потрібні видання та відстежувати прогрес читання. Основний сценарій — робота одного користувача на локальному комп’ютері без обов’язкової реєстрації та хмарних сервісів.

## Функціональні вимоги

- Додавання книги із назвою, автором і необов’язковим описом.
- Перегляд списку книг.
- Редагування та видалення записів із підтвердженням видалення.
- Пошук за назвою або автором.
- Зміна статусу читання: **Планую прочитати**, **Читаю**, **Прочитано**.
- Збереження даних між запусками програми.

## Нефункціональні вимоги

- Простий і зрозумілий вебінтерфейс українською мовою.
- Локальна робота без необхідності постійного доступу до Інтернету.
- Валідація введених даних та обробка типових помилок.
- Збереження даних у SQLite без зовнішнього сервера бази даних.
- Модульна структура коду, придатна для автоматизованого тестування.
- Відтворюваний запуск із документованими залежностями.

## Agent Harness

**Agent Harness** — інфраструктура, яка забезпечує AI-агенту контрольований доступ до контексту проєкту, правил і засобів розробки. Вона не є частиною інтерфейсу BookShelf та розвивається паралельно із застосунком.

Плановані компоненти:

1. **Data sources:** вихідний код, документація, історія Git-комітів і результати тестів.
2. **Knowledge layer:** окремий Obsidian vault із поняттями, архітектурними рішеннями, компонентами та зв’язками між нотатками.
3. **MCP connectors:** контрольоване читання й оновлення бази знань та отримання інформації з GitHub.
4. **Guardrails:** правила дозволених і заборонених дій агента, перевірки перед змінами.
5. **Skills:** повторно використовувані процедури генерації тестів, перевірки коду й оновлення документації.
6. **Orchestration:** послідовне виконання задач аналізу, реалізації, перевірки та документування.
7. **Evaluation:** оцінювання успішності завдань, результатів тестів і дотримання обмежень.

База знань зберігатиметься **окремо** від репозиторію застосунку, щоб доступ агента до неї здійснювався через визначені конектори.

## Цільові задачі AI-агента

1. Створювати та вдосконалювати компоненти BookShelf відповідно до вимог.
2. Генерувати й запускати автоматизовані тести для операцій із книгами.
3. Перевіряти зміни коду на відповідність правилам проєкту.
4. Аналізувати помилки та пропонувати обґрунтовані виправлення.
5. Оновлювати технічні нотатки в базі знань через MCP-конектор.
